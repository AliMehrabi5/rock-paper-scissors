# Rock Paper Scissors

A simple Rock Paper Scissors game built with HTML and JavaScript as part of [The Odin Project](https://www.theodinproject.com/).

## About

This project is a browser-based Rock Paper Scissors game that runs entirely in the browser console. The player competes against the computer for five rounds.

## Features

- Random computer choice: Rock, Paper, or Scissors.
- Player input using the browser's `prompt()` function.
- Round-by-round winner detection.
- Score tracking for both the player and the computer.
- Final result displayed in the browser console.

## Technologies Used

- HTML5
- JavaScript

## How to Run

1. Clone or download this repository.
2. Open `index.html` in your web browser.
3. Enter `rock`, `paper`, or `scissors` when prompted.
4. Play five rounds.
5. Open the browser developer tools (`F12`) and check the **Console** tab to see the results and final score.

## Rules

- Rock beats Scissors.
- Paper beats Rock.
- Scissors beats Paper.
- Identical choices result in a tie.

A tie does not award a point to either player.
